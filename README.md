# Movie Analytics Dashboard

## Project Overview
This project analyzes movie data to explore movie genres, languages, ratings, popularity, revenue, and runtime trends using Power BI.

## Tools Used
- Power BI
- Data Analysis
- Data Visualization

## Dashboard Features
1. Distribution of Movies by Genre
2. Distribution of Movies by Language
3. Movies by Release Year
4. Top 10 Rated Movies
5. Movie Popularity Over Time
6. Top 10 Movies by Revenue
7. Average Ratings by Genre and Language
8. Runtime Trends by Year and Revenue by Genre

## Business Objectives
- Understand the distribution of movies across genres and languages.
- Identify highly rated movies.
- Explore popularity and release trends over time.
- Compare movie revenue across titles and genres.
- Analyze rating patterns and runtime trends.

## Skills Demonstrated
- Data Cleaning and Preparation
- Data Analysis
- KPI and Chart Development
- Power BI Dashboard Design
- Data Visualization
